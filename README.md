# Next.js Project Setup and Basics

## Introduction
This repository, **alx-project-0x02-setup**, is part of the *SoloForge: Mastering Project Autonomy* program.  
Its purpose is to provide a structured foundation for learning and practicing modern web development using **Next.js**, **TypeScript**, and **Tailwind CSS**.

Through this project, you will:
- Scaffold a Next.js application with TypeScript and Tailwind CSS
- Implement basic routing using the Pages Router
- Build reusable components with TypeScript interfaces
- Create interactive UI elements such as modals and buttons
- Fetch and display data from external APIs
- Apply best practices in project structure, performance, and documentation

The goal is to help learners gain confidence in setting up and managing a professional-grade Next.js project, while reinforcing autonomy in solving real-world development tasks.

---

## Project Structure
The repository will evolve to include:
- `components/` → Reusable UI components (Button, Card, PostCard, UserCard, etc.)
- `interfaces/` → TypeScript interfaces for props and data models
- `pages/` → Application routes (Home, About, Posts, Users)
- `public/assets/images/` → Static assets
- `styles/` → Global and component-specific styles
- Configuration files (`tsconfig.json`, `next.config.js`, `.eslintrc.json`)
